今天我学习的主要内容就是搭建了自己的博客

刚开始我以为在GitHub上写博客应该和在word里写差不多吧，但没想到这么麻烦。

我先在浏览器搜索教程，找了个比较详细的教程开始搭建

我跟着教程安装一些软件，配置环境，中途也遇到了一些问题

我最开始在电脑的命令框输入代码，失败后找ai问原因才知道要在Git Bash里打

越按照教程走我越发现写博客很麻烦，要在我从没用过的记事本里写文字，还要使用MarkDown这种新鲜语法

对文档的操作也是要以输代码的方式进行。

这时我在英语的弱势就表现出来了，报错时根本看不懂问题原因，很多代码也记不住，只能结合ai一点一点前进

耗费了将近半天的时间，还是搭建出来了，也写了几个博客，还是很有成就感

把这段时间学的 Markdown 语法和 Hexo 命令记下来，以后忘了直接翻自己博客查。

一、Markdown 语法

1. 标题

几个 # 就是几级标题，# 后面必须空一格。

2. 文字格式

平时写字用的最多的几个：

  • 加粗：**文字** → 文字
  • 斜体：*文字* → 文字
  • 删除线：~~文字~~ → 文字
  • 行内代码：`文字` → 写函数名、变量名的时候用

三、踩过的坑

1. YAML 冒号后面必须空一格

✅ 正确：tags: 随笔
❌ 错误：tags:随笔

不然整个配置文件直接崩，报一堆莫名其妙的错。

2. 命令行里要用英文引号

中文引号会导致终端卡住，按回车只换行不执行命令。
遇到这种情况按 Ctrl + C 取消，重新输入就行。

3. hexo 命令不能在 themes 文件夹里跑

进到主题文件夹里跑 hexo 会报一堆 Usage 帮助信息。
cd ../.. 退回到博客根目录就好了。

4. 改完配置一定要跑 hexo clean

不然旧缓存会留在本地，改了东西看不到效果。

261030生活日常

发表于 2026-10-30

第一次记录自己的生活，也不知道该怎么写，
反正大概也不会有其他人看我的博客，就记流水账吧。

##早上

早上依旧是七点起床，比较困但还是强迫自己起来了。
煮上鸡蛋去洗漱，洗漱完开始吃早饭，四个全蛋加60g燕麦，榨菜吃完了，就着20g南瓜子吃完。

之前直接吃燕麦加鸡蛋差点吃吐，但现在习惯了好了挺多，不过还是很难吃。

##上午

上午没课，我开始上网，想学点东西但不怎么想学b站上的c语言课程。
在上网过程中看到了写博客，于是开始搜教程结合AI开始搭建自己的博客。

##下午

时间很快就到11点了，最近在吃轻禾小厨的外卖，不是多好吃，而是感觉要健康一点，也挺便宜。
吃完休息一会就要上课了，课程很无聊，我基本没听，我对造纸不怎么感兴趣，很快就到了下午4：50，课上完了回宿舍。

##晚上

回宿舍后先把明天要用的实验预习报告写好，写完了就吃晚饭了。

吃了一根香蕉和一袋鸡胸肉，吃完了歇会吃彩椒和肌酸，补钾片。

##插曲

正打算把今天的博客写了，之前在健身房遇到的大叔发消息过来了。

我很早就怀疑他是gay，果然没错，他把我推给了一个人网名叫什么小虎的，上来第一句就是小熊你好，明明完全不认识上来就套近乎，还要交换照片。

我那遇到过这种情况，和健身房认识的那个大叔问了问，他说”我把一个可爱的小熊推给他了“，真把我恶心坏了，赶紧拉开距离，还发了朋友圈。

这些事我也懒得说了，每天就固定写一篇生活一篇学习吧，写完这两个博客卷点烟就睡吧，尽量11：30睡着。
